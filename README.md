# BBM418 Programming Assignments – Spring 2023–2024

This repository contains three programming assignments prepared for the **BBM 418 - Computer Vision Laboratory** course at Hacettepe University. Each assignment covers core computer vision topics such as edge detection, image classification using Bag of Visual Words, and deep learning with CNNs and transfer learning.

---

## 📄 Assignments

### 1. [Programming Assignment 1 – License Plate Detection using Hough Transform](./computer_vision_assignment_1)

**Goal:** Implement a pipeline for detecting license plates using edge detection (Sobel & Canny) and the Hough Transform.

**Highlights:**
- Understand edge detection via Sobel and Canny.
- Implement Hough Transform from scratch.
- Visualize results on plate images.
- Compare Sobel and Canny-based Hough results.

---

### 2. [Programming Assignment 2 – Image Classification with Bag of Visual Words](./computer_vision_assignment_2)

**Goal:** Build an image classification pipeline using Bag of Visual Words (BoVW) with keypoint descriptors and KMeans clustering.

**Highlights:**
- Keypoint detection (SIFT, SURF, ORB).
- Feature extraction and matching.
- Visual vocabulary construction with KMeans.
- k-NN classification with different distance metrics.
- Performance comparison between descriptor types.

---

### 3. [Programming Assignment 3 – CNN and EfficientNet-based Classification](./computer_vision_assignment_3)

**Goal:** Perform animal image classification using both a custom CNN and transfer learning with EfficientNet.

**Highlights:**
- Design and train a custom CNN with PyTorch.
- Apply data augmentation, dropout, and tuning.
- Train EfficientNet with frozen and partially trainable layers.
- Evaluate and compare both approaches via accuracy and confusion matrix.
